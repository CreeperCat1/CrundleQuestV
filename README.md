# Release
There is a release version that is already built: [HERE](https://github.com/CreeperCat1/CrundleQuestV/releases/tag/Release)

## Disclaimer
This is my first project with C++ so this code probably sucks.

There's basically no dialogue, if you would like to add some you can write it inside the vector called "dialogueList" in "gameManager.cpp".

There's a few story notes that I came up with and left in there, you can decide whether to use them or not.

Let me know if you write any dialogue for it and I might add it.

(Need to download if building yourself)
- SDL3
- SDL3_image
- SDL3_ttf
- SDL3_mixer
